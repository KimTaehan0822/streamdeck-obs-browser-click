# OBS Browser Click (스트림덱 플러그인)

**한국어** | [English](README.en.md) | [日本語](README.ja.md)

OBS의 **사용자 지정 독**과 **브라우저 소스** 안에 있는 버튼을 Elgato Stream Deck 키로 누르는 플러그인입니다. 상호작용 창을 열 필요가 없고, 독이 다른 탭 뒤에 있어도 눌립니다.

예) 위플랩 후원 알림 넘기기, 씨미 건너뛰기, 치지직 TTS 넘기기, 투네이션 스킵.

## 다운로드

[최신 릴리즈](https://github.com/KimTaehan0822/streamdeck-obs-browser-click/releases/latest) 페이지에서 `OBS-Browser-Click-StreamDeck-v<버전>.zip`을 받아 압축을 풉니다. 안에 들어 있는 파일은 아래와 같습니다.

- `OBS-Browser-Click.streamDeckPlugin`: 설치 파일
- 사용설명서 PDF (언어별로 하나씩)
  - `OBS Browser Click 스트림덱 플러그인 사용설명서.pdf`: 한국어
  - `OBS Browser Click Stream Deck Plugin Manual (English).pdf`: 영어
  - `OBS Browser Click Stream Deck プラグイン 取扱説明書 (日本語).pdf`: 일본어
- `LICENSE.txt`: 이 플러그인의 라이선스 (MIT)
- `THIRD-PARTY-NOTICES.txt`: 함께 쓰인 오픈소스 고지

## 필요한 것

- Windows 10 이상
- Stream Deck 소프트웨어 7.3 이상
- OBS Studio (Windows 64비트)
- 누를 리모컨(위플랩·씨미·치지직·투네이션)이 OBS에 사용자 지정 브라우저 독이나 브라우저 소스로 열려 있어야 합니다.

## 빠른 시작

### 1. 플러그인 설치

`OBS-Browser-Click.streamDeckPlugin`을 더블클릭하고, Stream Deck 소프트웨어가 설치할지 물으면 승인합니다.

### 2. OBS를 디버깅 옵션으로 켜기

플러그인은 OBS의 **원격 디버깅 포트**로 페이지 안의 버튼을 누릅니다. OBS가 `--remote-debugging-port=9222` 옵션으로 켜져 있어야 합니다.

1. 아무 액션이나 키에 올리고 클릭한 뒤, 설정 화면 맨 아래의 **[OBS 바로가기 설정]**을 누릅니다.
2. 내 바탕화면과 시작 메뉴에 **OBS Studio (Browser Click)** 바로가기가 생깁니다. 작업 표시줄에 고정된 OBS가 있으면 거기에도 옵션이 붙습니다. 관리자 권한은 필요 없습니다.
3. OBS를 완전히 끄고 이 바로가기로 다시 켭니다.

원래 있던 "OBS Studio" 아이콘(공용 바탕화면, 시작 메뉴)으로 켜면 옵션이 빠집니다. 그 아이콘은 OBS 업데이트 때 다시 만들어지므로 플러그인이 고치지 않습니다.

<details><summary>손으로 붙이는 법</summary>

OBS 바로가기 → 오른쪽 클릭 → **속성** → **대상** 칸 맨 끝에 한 칸 띄우고 `--remote-debugging-port=9222`를 붙입니다. 예: `"C:\Program Files\obs-studio\bin\64bit\obs64.exe" --remote-debugging-port=9222`. **시작 위치**는 `C:\Program Files\obs-studio\bin\64bit`이어야 합니다.

</details>

### 3. 첫 키 만들기

1. 액션 목록의 **OBS Browser Click → 위플랩 리모컨**을 키에 끌어다 놓습니다.
2. 설정 화면의 **동작**에서 **알림 취소(넘기기)**를 고릅니다.
3. 후원 알림이 나올 때 키를 누르면 넘어갑니다. 처음에는 **테스트 알림**으로 확인해 보세요.

## 디버깅 모드 주의

- **이 PC 안의 다른 프로그램**은 OBS 안의 페이지(로그인된 치지직·씨미 스튜디오 등)를 보고 조작할 수 있습니다. 인터넷이나 일반 웹페이지에서는 들어올 수 없습니다(포트는 `127.0.0.1`에만 열리고, 웹페이지의 접속은 OBS가 거절합니다). 모르는 프로그램을 설치하지 마세요.
- **포트 충돌**: 크롬 개발 모드처럼 다른 프로그램이 같은 포트를 쓰면 OBS가 포트를 못 열 수 있습니다. 포트 너머가 OBS가 아니면 플러그인은 아무것도 누르지 않고 키에 `OFFLINE`을 띄웁니다. 아래 "설정"에서 포트를 바꾸고 [OBS 바로가기 설정]을 다시 누르세요.
- **옵션 없이 켜짐**: 원래 아이콘이나 다른 프로그램으로 OBS를 켜면 옵션이 빠지고, 키에 `디버그 꺼짐`이 뜹니다.
- **OBS 업데이트**: 공용 바로가기는 다시 만들어지지만, 새 바로가기와 작업 표시줄 아이콘은 그대로 남습니다.
- **성능** 영향은 거의 없습니다.

## 액션 목록

| 액션 | 고를 수 있는 동작 |
| --- | --- |
| 위플랩 리모컨 | 알림 일시정지/재개 ●, 알림 취소(넘기기), 알림 모두 취소, 목록 새로고침, 테스트 알림, 타이머 시작·정지·시간·업타임·삭제, 아바타 게임 시작·취소, 전광판 현재 취소·모두 취소, 투표 시작·중지·결과 |
| 씨미 리모컨 | 일시정지, 건너뛰기, 채팅·응원·영상·미션 후원 켜기/끄기 ●, 워프: 팔로잉만 받기 ●, 시청자 보내기 |
| 치지직 리모컨 | TTS 넘기기, 알림 정지 |
| 투네이션 리모컨 | 알림 일시정지 ●, 스킵 |
| 범용 클릭 | 목록에 없는 버튼이나 화면의 한 지점을 직접 고르기 |

● 표시는 켜짐/꺼짐을 키가 따라갑니다(켜지면 테두리가 하늘색). 스트림덱 앱에서 상태별 아이콘·제목을 바꿀 수 있습니다.

**범용 클릭**은 **페이지**를 고른 뒤 **방식**을 정합니다. 브라우저 소스는 `[소스] 위플랩 알림`처럼 OBS에서 지은 이름으로, 사용자 지정 독은 웹페이지 제목으로 나옵니다.
- **버튼으로 찾기**: 페이지의 버튼이 글자로 나옵니다. 글자가 없는 아이콘 버튼은 **CSS 선택자**를 적습니다.
- **위치 찍기**: **[화면 불러오기]**로 뜬 캡처에서 누를 곳을 찍습니다. 클릭은 그 페이지 안으로만 가고 실제 마우스는 움직이지 않습니다. 독·브라우저 소스 크기를 바꾸면 위치가 어긋나니 다시 찍어 주세요. 페이지를 스크롤하면 키에 `스크롤 바뀜`이 뜨고, 키를 한 번 누르면 찍을 때의 스크롤로 되돌립니다(클릭은 다시 누를 때). 설정의 **[스크롤 되돌리기]** 버튼으로도 되돌릴 수 있고, **스크롤이 바뀌면 키로 되돌리기**를 끄면 ⚠만 뜹니다. 스크롤은 찍은 곳이 들어 있는 칸(후원 목록, 채팅창 등)을 기준으로 보고, 화면이 바뀌어 그 칸을 못 찾으면 누르지 않고 ⚠를 띄웁니다. 버튼으로 누를 수 있으면 **버튼으로 찾기**가 더 튼튼합니다.

## 설정

| 항목 | 기본값 | 뜻 |
| --- | --- | --- |
| 디버깅 포트 | `9222` (비워 두면) | OBS 옵션의 숫자와 같아야 함. 모든 액션 공통 |
| [OBS 바로가기 설정] | | 위 포트로 OBS를 켜는 바로가기 만들기. 포트를 바꾸면 다시 누르기 |

## 키에 뜨는 표시

| 표시 | 뜻 | 할 일 |
| --- | --- | --- |
| 동작 이름 | 정상 | 스트림덱 앱에서 제목을 직접 적으면 그 제목을 그대로 둡니다 |
| **OFFLINE** | OBS가 꺼져 있거나 포트를 다른 프로그램이 씀 | 새 바로가기로 OBS 켜기, 포트 확인 |
| **디버그 꺼짐** | OBS가 디버깅 옵션 없이 켜짐 | OBS를 끄고 OBS Studio (Browser Click)로 다시 켜기 |
| **없음** | 그 리모컨이 OBS에 없거나 동작을 안 고름 | 리모컨 독 추가, 동작 고르기 |
| **스크롤 바뀜** | 위치 찍기 키의 페이지가 찍을 때와 다르게 스크롤됨 | 키를 한 번 누르면 스크롤만 되돌림(설정에서 끄면 ⚠만). 다시 누르면 클릭 |
| ⚠ (잠깐) | 눌렀는데 버튼을 못 찾음 | 아무것도 누르지 않았습니다. 리모컨 화면이 바뀌었는지 확인 |

## 직접 빌드하기

```bash
npm install
npm test          # tsc + node --test
npm run bundle    # com.haeunga0822.obs-browser-click.sdPlugin/bin/plugin.js
npx streamdeck link com.haeunga0822.obs-browser-click.sdPlugin
node docs/manual/make-pdf.mjs   # 사용설명서 PDF (Edge, Noto Sans KR/JP 필요)
```
