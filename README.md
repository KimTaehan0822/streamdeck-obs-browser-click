# OBS Browser Click (스트림덱 플러그인)

OBS의 **사용자 지정 독**과 **브라우저 소스** 안에 있는 버튼을 스트림덱 키로 누릅니다.
상호작용 창을 열 필요가 없고, 독이 다른 탭 뒤에 있어도 눌립니다.

예) 위플랩 후원 알림 넘기기, 씨미 건너뛰기, 치지직 TTS 넘기기, 투네이션 스킵.

## 1. OBS를 디버깅 옵션으로 켜기 (꼭 필요)

플러그인은 OBS의 "원격 디버깅 포트"로 페이지 안의 버튼을 누릅니다. OBS 바로가기에 옵션을 한 번 붙여 두세요.

1. 바탕화면(또는 작업 표시줄)의 OBS 바로가기 → 오른쪽 클릭 → **속성**
2. **대상** 칸 맨 끝에 한 칸 띄우고 아래를 붙입니다.
   ```
   --remote-debugging-port=9222
   ```
   예: `"C:\Program Files\obs-studio\bin\64bit\obs64.exe" --remote-debugging-port=9222`
3. **시작 위치**가 `C:\Program Files\obs-studio\bin\64bit` 인지 확인 → 확인
4. OBS를 완전히 끄고 이 바로가기로 다시 켭니다.

잘 켜졌는지 보려면 브라우저 주소창에 `http://127.0.0.1:9222/json/list` 를 열어 보세요. 페이지 목록이 나오면 됩니다.

> 주의: 이 옵션이 켜져 있는 동안에는 **이 PC 안의 다른 프로그램도** OBS 안의 페이지(리모컨 등)에 접근할 수 있습니다. 포트는 이 PC 안(127.0.0.1)에서만 열립니다.

## 2. 키 종류

### 위플랩 리모컨 · 씨미 리모컨 · 치지직 리모컨 · 투네이션 리모컨
서비스마다 액션이 따로 있습니다. 키를 올린 뒤 설정 창의 **동작**에서 그 리모컨의 버튼을 고릅니다. OBS에 해당 리모컨이 독이나 브라우저 소스로 열려 있어야 합니다.

| 액션 | 동작 |
|---|---|
| 위플랩 리모컨 (`weflab.com/alertlist?mode=remote`) | 알림 일시정지/재개 ●, 알림 취소(넘기기), 알림 모두 취소, 목록 새로고침, 테스트 알림, 타이머 시작·정지·시간·업타임·삭제, 아바타 게임 시작·취소, 전광판 현재 취소·모두 취소, 투표 시작·중지·결과 |
| 씨미 리모컨 (`studio.ci.me/.../rc`) | 일시정지, 건너뛰기, 채팅·응원·영상·미션 후원 켜기/끄기 ●, 워프: 팔로잉만 받기 ●, 시청자 보내기 |
| 치지직 리모컨 (`studio.chzzk.naver.com/.../remotecontrol`) | TTS 넘기기, 알림 정지 |
| 투네이션 리모컨 (`toon.at/widget/controller/...`) | 알림 일시정지 ●, 스킵 |

● 표시는 켜짐/꺼짐이 키 모양에 따라 나옵니다(테두리가 하늘색이면 켜짐). 스트림덱 앱에서 상태별 아이콘·제목을 바꿀 수 있습니다.

### 범용 클릭
목록에 없는 버튼을 직접 고릅니다.
1. **페이지**: 지금 OBS에 열린 페이지 중 하나를 고릅니다(OBS를 방금 켰다면 **목록 새로고침**).
2. **버튼**: 그 페이지의 버튼이 글자로 나옵니다. 같은 글자가 여럿이면 `시작 (2)`처럼 번호가 붙습니다.
3. 글자가 없는 아이콘 버튼은 **CSS 선택자**를 적습니다(적으면 위 버튼 선택보다 우선).
4. 버튼이 아닌 곳(알림창 영역 등)은 **방식 → 위치 찍기**를 고르고 **[화면 불러오기]**로 뜬 캡처에서 누를 곳을 찍습니다. 클릭은 그 페이지 안으로만 가고 실제 마우스는 움직이지 않습니다. 독·브라우저 소스 크기를 바꾸면 위치가 어긋나니 다시 찍어 주세요.

## 3. 키에 나오는 글자

- 평소: 동작 이름(스트림덱 앱에서 제목을 직접 적으면 그 제목을 그대로 둡니다)
- `OFFLINE`: OBS가 꺼져 있거나 디버깅 옵션 없이 켜짐
- `없음`: 그 페이지(리모컨)가 OBS에 없거나 동작을 아직 안 고름
- 눌렀는데 버튼을 찾지 못하면 키에 경고(⚠)가 잠깐 뜨고 **아무것도 누르지 않습니다.**

## 4. 설정

- **디버깅 포트**: 비워 두면 9222. OBS 옵션의 숫자와 같아야 합니다.
