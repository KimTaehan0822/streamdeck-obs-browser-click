# OBS Browser Click (Stream Deck プラグイン)

[한국어](README.md) | [English](README.en.md) | **日本語**

OBS の**カスタムブラウザドック**や**ブラウザソース**の中にあるボタンを Elgato Stream Deck のキーで押すプラグインです。「対話」ウィンドウを開く必要はなく、ドックが別のタブの後ろにあっても押せます。

例: Weflab の投げ銭アラートのスキップ、ci.me のスキップ、Chzzk の TTS スキップ、Toonation のスキップ。

プラグインの設定画面は韓国語です。以下では韓国語の項目名をそのまま書き、意味を添えています。

## 必要なもの

- Windows 10 以降
- Stream Deck ソフトウェア 7.3 以降
- OBS Studio(Windows 64 ビット)
- 押したいリモコン(Weflab・ci.me・Chzzk・Toonation)が、OBS にカスタムブラウザドックかブラウザソースとして開かれていること

## クイックスタート

### 1. プラグインのインストール

`OBS-Browser-Click.streamDeckPlugin` をダブルクリックし、Stream Deck ソフトウェアがインストールするか聞いてきたら承認します。

### 2. OBS をデバッグオプション付きで起動

プラグインは OBS の**リモートデバッグポート**を通してページ内のボタンを押します。OBS を `--remote-debugging-port=9222` 付きで起動する必要があります。

1. どれかのアクションをキーに置いてクリックし、設定画面の一番下の **[OBS 바로가기 설정]**(OBS ショートカット設定)を押します。
2. デスクトップとスタートメニューに **OBS Studio (Browser Click)** ショートカットができます。タスクバーに OBS をピン留めしていれば、そのアイコンにもオプションが付きます。管理者権限は不要です。
3. OBS を完全に終了し、このショートカットから起動し直します。

元からある「OBS Studio」アイコン(共有デスクトップ、スタートメニュー)から起動するとオプションは付きません。これらは OBS のアップデートのたびに作り直されるため、プラグインは変更しません。

<details><summary>手動で付ける方法</summary>

OBS のショートカットを右クリック → **プロパティ** → **リンク先**の末尾に半角スペースを入れて `--remote-debugging-port=9222` を付けます。例: `"C:\Program Files\obs-studio\bin\64bit\obs64.exe" --remote-debugging-port=9222`。**作業フォルダー**は `C:\Program Files\obs-studio\bin\64bit` にします。

</details>

### 3. 最初のキーを作る

1. アクション一覧の **OBS Browser Click → 위플랩 리모컨**(Weflab リモコン)をキーにドラッグします。
2. **동작**(動作)で **알림 취소(넘기기)**(アラート取り消し/スキップ)を選びます。
3. アラートが出ているときにキーを押すとスキップされます。最初は **테스트 알림**(テストアラート)で確かめてください。

## デバッグモードの注意

- **この PC 内の他のプログラム**は、OBS 内のページ(ログイン済みの Chzzk・ci.me スタジオなど)を見たり操作したりできます。インターネットや通常の Web ページからは入れません(ポートは `127.0.0.1` だけで開き、Web ページからの接続は OBS が拒否します)。知らないプログラムをインストールしないでください。
- **ポートの競合**: Chrome のデバッグモードなど、他のプログラムが同じポートを使うと OBS がポートを開けないことがあります。ポートの先が OBS でなければ、プラグインは何も押さずキーに `OFFLINE` を表示します。下の「設定」でポートを変え、[OBS 바로가기 설정] をもう一度押してください。
- **オプションなしで起動**: 元のアイコンや他のプログラムから OBS を起動するとオプションが付かず、キーに `디버그 꺼짐`(デバッグオフ)が出ます。
- **OBS のアップデート**: 共有ショートカットは作り直されますが、新しいショートカットとタスクバーのアイコンはそのまま残ります。
- **パフォーマンス**への影響はほとんどありません。

## アクション一覧

| アクション | 選べる動作 |
| --- | --- |
| 위플랩 리모컨(Weflab リモコン) | アラート一時停止/再開 ●、アラート取り消し(スキップ)、アラートをすべて取り消し、一覧の更新、テストアラート、タイマー開始・停止・時間・アップタイム・削除、アバターゲーム開始・取り消し、電光掲示板の現在を取り消し・すべて取り消し、投票開始・中止・結果 |
| 씨미 리모컨(ci.me リモコン) | 一時停止、スキップ、チャット・応援・動画・ミッション投げ銭のオン/オフ ●、ワープ: フォロワーのみ受け取る ●、視聴者を送る |
| 치지직 리모컨(Chzzk リモコン) | TTS スキップ、アラート停止 |
| 투네이션 리모컨(Toonation リモコン) | アラート一時停止 ●、スキップ |
| 범용 클릭(汎用クリック) | 一覧にないボタンや画面の一点を自分で選ぶ |

● の付いた動作はオン/オフにキーが連動します(オンで枠が水色)。Stream Deck アプリで状態ごとのアイコン・タイトルを変えられます。

**汎用クリック**は **페이지**(ページ)を選んでから **방식**(方式)を決めます。
- **버튼으로 찾기**(ボタンで探す): ページのボタンが文字で一覧に出ます。文字のないアイコンボタンは **CSS 선택자**(CSS セレクター)を書きます。
- **위치 찍기**(位置を指定): **[화면 불러오기]**(画面の読み込み)で出たキャプチャで押す場所をクリックします。クリックはそのページの中にだけ届き、実際のマウスは動きません。ドックやブラウザソースのサイズを変えたら、指定し直してください。

## 設定

| 項目 | 初期値 | 意味 |
| --- | --- | --- |
| 디버깅 포트(デバッグポート) | `9222`(空欄のとき) | OBS のオプションの数字と同じにする。全アクション共通 |
| [OBS 바로가기 설정] | | このポートで OBS を起動するショートカットを作る。ポートを変えたら再度押す |

## キーの表示

| 表示 | 意味 | 対処 |
| --- | --- | --- |
| 動作の名前 | 正常 | Stream Deck アプリでタイトルを入れると、そのタイトルのまま残ります |
| **OFFLINE** | OBS が起動していない、または他のプログラムがポートを使用 | 新しいショートカットで OBS を起動、ポートを確認 |
| **디버그 꺼짐**(デバッグオフ) | OBS がデバッグオプションなしで起動 | OBS を終了し OBS Studio (Browser Click) から起動し直す |
| **없음**(なし) | そのリモコンが OBS にない、または動作を選んでいない | リモコンのドックを追加、動作を選ぶ |
| ⚠(一瞬) | 押したときにボタンが見つからなかった | 何も押されていません。リモコンの画面が変わっていないか確認 |
