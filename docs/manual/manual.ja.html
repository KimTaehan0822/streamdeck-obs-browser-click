OBS Browser Click Stream Deck プラグイン 取扱説明書

2026-11-11 (v0.1.1)

OBS のカスタムブラウザドックやブラウザソースの中にあるボタン(Weflab・ci.me・Chzzk・Toonation のリモコンなど)を Stream Deck のキーで押すプラグインです。「対話」ウィンドウを開く必要はなく、ドックが別のタブの後ろに隠れていても押せます。

作者: 김탄2(Kimtan2)

プラグインの設定画面は韓国語です。この説明書では、画面に表示される韓国語の項目名をそのまま書き、意味を添えています。

必要なもの

項目必要なもの
パソコンWindows 10 以降
Stream Deck アプリStream Deck ソフトウェア 7.3 以降
OBSOBS Studio(Windows 64 ビット)
インストールファイルOBS-Browser-Click.streamDeckPlugin

押したいリモコン(Weflab、ci.me、Chzzk、Toonation)が、OBS にカスタムブラウザドックまたはブラウザソースとして開かれている必要があります。

ステップ 1: プラグインのインストール

  1. OBS-Browser-Click.streamDeckPlugin をダブルクリックします。

  2. Stream Deck アプリが開き、インストールするか聞かれます。インストールを押します。上書きするか聞かれた場合もインストールを選びます。

  3. 右側のアクション一覧に OBS Browser Click カテゴリが追加されたことを確認します。

ステップ 2: OBS をデバッグオプション付きで起動

プラグインは OBS のリモートデバッグポートを通して OBS 内のページに入り、ボタンを押します。そのため OBS を --remote-debugging-port=9222 オプション付きで起動する必要があります。ボタン一つでこのオプション付きのショートカットを作れます。

  1. OBS Browser Click のアクションをどれか一つキーにドラッグし、クリックします。

  2. 設定画面の一番下にある [OBS 바로가기 설정](OBS ショートカット設定)を押します。

  3. デスクトップとスタートメニューに「OBS Studio (Browser Click)」を作ったというメッセージが出れば完了です。タスクバーに OBS をピン留めしている場合は、そのアイコンにもオプションが付きます。

  4. OBS を完全に終了し、新しくできた OBS Studio (Browser Click) ショートカット(またはタスクバーの OBS)から起動し直します。

注意: 元からある「OBS Studio」アイコン(共有デスクトップ、スタートメニュー)から起動すると、オプションは付きません。これらは OBS のアップデートのたびに作り直されるため、プラグインは変更しません。新しいショートカットはユーザーフォルダにあるので、OBS をアップデートしても消えません。

手動で付ける方法: OBS のショートカットを右クリック → プロパティ → リンク先の末尾に半角スペースを入れて --remote-debugging-port=9222 を付けます。作業フォルダーは C:\Program Files\obs-studio\bin\64bit にします。

確認方法: キーに OFFLINE や 디버그 꺼짐(デバッグオフ)が出なければ大丈夫です。ブラウザで http://127.0.0.1:9222/json/list を開き、ページ一覧が出ることでも確認できます。

デバッグオプションについて知っておくこと

  • この PC 内の他のプログラムは、OBS 内のページ(ログイン済みの Chzzk・ci.me スタジオ、Weflab リモコンなど)を見たり操作したりできます。インターネットや通常のブラウザの Web ページからは入れません(ポートはこの PC 内の 127.0.0.1 だけで開き、Web ページからの接続は OBS が拒否します)。知らないプログラムをインストールしないことが一番大切です。

  • ポートの競合: Chrome のデバッグモードなど、他のプログラムが同じポートを使うと、OBS がポートを開けないことがあります。ポートの先が OBS でない場合、プラグインは何も押さず、キーに OFFLINE を表示します。下の「設定」でポートを変え、[OBS 바로가기 설정] をもう一度押してください。

  • オプションなしで起動: 元のアイコンや他のプログラムから OBS を起動するとオプションが付きません。このときキーに 디버그 꺼짐(デバッグオフ)が出ます。

  • OBS のアップデート: インストーラーが共有ショートカットを作り直します。新しいショートカットとタスクバーのアイコンはそのまま残りますが、もしオプションが消えていたら [OBS 바로가기 설정] をもう一度押してください。

  • パフォーマンス: 影響はほとんどありません。ポートは待っているだけで、プラグインは 1 秒に 1 回状態を確認します。

ステップ 3: 最初のキーを作る

Weflab の投げ銭アラートをキー一つでスキップする例です。

  1. Weflab のダッシュボードでリモコンの URL をコピーし、OBS のメニュー ドック → カスタムブラウザドックに追加します(すでにあれば飛ばします)。

  2. アクション一覧の OBS Browser Click → 위플랩 리모컨(Weflab リモコン)をキーにドラッグします。

  3. 設定画面の 동작(動作)で 알림 취소(넘기기)(アラート取り消し/スキップ)を選びます。

  4. キーに「알림 취소(넘기기)」と表示されます。アラートが出ているときに押すとスキップされます。

最初は Weflab の 테스트 알림(テストアラート)で確かめてみてください。

● の付いた動作は、ページのオン/オフにキーが連動します。オンのときはキーの枠が水色になります。Stream Deck アプリでキーの下の 2 つの点(左がオフ、右がオン)を押すと、状態ごとにアイコンとタイトルを変えられます。

汎用クリック(범용 클릭)

一覧にないボタンや、OBS 内の任意のページのボタンを押すときに使います。

  1. 페이지(ページ): OBS で開いているページを一つ選びます。OBS を起動した直後やドックを追加した後は [목록 새로고침](一覧の更新)を押します。ブラウザソースは [소스] アラート のように OBS で付けた名前で表示され(소스 はソースの意味)、カスタムドックは Web ページのタイトルで表示されます。

  2. 방식(方式): 버튼으로 찾기(ボタンで探す)か 위치 찍기(位置を指定)を選びます。

  3. ボタンで探す: 버튼(ボタン)一覧にページのボタンが文字で表示されます。同じ文字が複数あると 시작 (2) のように番号が付きます。文字のないアイコンボタンは CSS 선택자(CSS セレクター)に書きます(書くとボタン一覧より優先されます)。

  4. 位置を指定: [화면 불러오기](画面の読み込み)を押すとページのキャプチャが出ます。押したい場所をクリックすると赤い点が付き、X、Y が入ります。

位置指定の注意: ドックやブラウザソースのサイズを変えると、同じ座標が別の場所を押すことがあります。サイズを変えた後は必ず [화면 불러오기] で位置を指定し直してください。クリックはそのページの中にだけ届き、実際のマウスカーソルは動きません。ページをスクロールすると、キーに 스크롤 바뀜(スクロール変更)が出ます。キーを一度押すと位置を指定したときのスクロールに戻し(クリックはしません)、もう一度押すとクリックします。設定画面の [스크롤 되돌리기](スクロールを戻す)ボタンでも戻せます。스크롤이 바뀌면 키로 되돌리기(キーでスクロールを戻す)をオフにすると、キーは ⚠ だけを出します。スクロールは、指定した位置を含む枠(投げ銭一覧やチャット欄など)を基準に見ます。リモコンの画面が変わってその枠が見つからないときは何も押さず ⚠ を出すので、位置を指定し直してください。ボタンで押せる場合は 버튼으로 찾기(ボタンで探す)のほうが確実です。

キーの表示

キーにはふだん選んだ動作の名前が出ます。Stream Deck アプリのタイトル欄に自分で文字を入れると、プラグインはそのタイトルを変えません。文字が切れる場合は、タイトル欄の横の T ボタンで文字を小さくしてください。
