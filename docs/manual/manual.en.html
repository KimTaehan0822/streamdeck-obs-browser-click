OBS Browser Click Stream Deck Plugin Manual

2026-11-11 (v0.1.1)

This plugin presses buttons inside OBS custom browser docks and browser sources (Weflab, ci.me, Chzzk and Toonation remotes, and more) from a Stream Deck key. You don't need to open the Interact window, and it works even when the dock is hidden behind another tab.

Made by 김탄2 (Kimtan2)

The plugin's settings screen is in Korean. This manual gives each Korean label as it appears on screen, followed by its meaning.

The remote you want to press (Weflab, ci.me, Chzzk, Toonation) must be open in OBS as a custom browser dock or a browser source.

Step 1: Install the plugin

  1. Double-click OBS-Browser-Click.streamDeckPlugin.

  2. The Stream Deck app opens and asks whether to install. Click Install. If it asks to replace an older version, choose Install as well.

  3. Check that an OBS Browser Click category appears in the action list on the right.

Step 2: Start OBS with the debug option

The plugin reaches the pages inside OBS through OBS's remote debugging port. OBS must be started with --remote-debugging-port=9222. One button makes a shortcut with this option for you.

  1. Drag any OBS Browser Click action onto a key and click it.

  2. At the bottom of the settings screen, click [OBS 바로가기 설정] (set up OBS shortcut).

  3. When the message says it made "OBS Studio (Browser Click)" on the desktop and Start menu, you're done. If OBS is pinned to the taskbar, that icon gets the option too.

  4. Close OBS completely and start it again from the new OBS Studio (Browser Click) shortcut (or the taskbar OBS).

Note: the original "OBS Studio" icons (public desktop, Start menu) still start OBS without the option. The OBS installer recreates them on every update, so the plugin leaves them alone. The new shortcut lives in your own user folder, so OBS updates don't remove it.

Doing it by hand: right-click an OBS shortcut → Properties → add a space and --remote-debugging-port=9222 at the end of Target. Start in must be C:\Program Files\obs-studio\bin\64bit.

To check: keys don't show OFFLINE or 디버그 꺼짐 (debug off). Opening http://127.0.0.1:9222/json/list in a browser also shows a list of pages.

Things to know about the debug option

  • Other programs on this PC can see and operate the pages inside OBS (your signed-in Chzzk and ci.me studios, the Weflab remote and so on). The internet and ordinary web pages can't get in: the port opens on this PC only (127.0.0.1), and OBS rejects connections from web pages. Don't install programs you don't trust.

  • Port conflicts: if another program (such as Chrome in debug mode) uses the same port, OBS may not be able to open it. When the port doesn't belong to OBS, the plugin presses nothing and the key shows OFFLINE. Change the port under "Settings" below and click [OBS 바로가기 설정] again.

  • Started without the option: starting OBS from the original icon, or from another program, leaves the option out. Keys then show 디버그 꺼짐 (debug off).

  • OBS updates: the installer recreates the public shortcuts. Your new shortcut and the taskbar icon stay. If the option ever goes missing, click [OBS 바로가기 설정] once more.

  • Performance: practically no effect. The port only waits, and the plugin checks state once a second.

Step 3: Make your first key

This example skips a Weflab donation alert with one key.

  1. Copy the remote URL from your Weflab dashboard and add it in OBS under Docks → Custom Browser Docks (skip this if it's already there).

  2. Drag OBS Browser Click → 위플랩 리모컨 (Weflab remote) onto a key.

  3. In the settings screen, under 동작 (action), choose 알림 취소(넘기기) (cancel alert / skip).

  4. The key shows "알림 취소(넘기기)". Press it while an alert plays to skip it.

Try it first with Weflab's 테스트 알림 (test alert).

Actions marked ● follow the on/off state on the page. When it's on, the key gets a sky-blue ring. In the Stream Deck app you can click the two dots under the key (left off, right on) to set a different icon and title for each state.

Custom click (범용 클릭)

Use it for buttons that aren't in the lists, on any page open in OBS.

  1. 페이지 (page): choose one of the pages open in OBS. If you just started OBS or added a dock, click [목록 새로고침] (refresh list). Browser sources are listed by their OBS name, like [소스] My Alerts (소스 means source); custom docks are listed by their page title.

  2. 방식 (method): choose 버튼으로 찾기 (find by button) or 위치 찍기 (pick a point).

  3. Find by button: the 버튼 (button) list shows the page's buttons by their text. Buttons with the same text get a number, like 시작 (2). For an icon button without text, enter a CSS 선택자 (CSS selector); it wins over the button list.

  4. Pick a point: click [화면 불러오기] (load screen) to see a capture of the page, then click where to press. A red dot marks it and X, Y fill in.

About picked points: if you resize the dock or browser source, the same coordinates may land somewhere else. After resizing, pick the point again with [화면 불러오기]. The click goes to that page only, and your real mouse cursor doesn't move.

Key titles

A key normally shows the name of its action. If you type your own text in the Stream Deck app's Title field, the plugin leaves it as it is. If text gets cut off, make it smaller with the T button next to the Title field.
