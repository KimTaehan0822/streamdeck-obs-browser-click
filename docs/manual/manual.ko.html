OBS Browser Click 스트림덱 플러그인 사용설명서

2026-11-11

OBS의 사용자 지정 독과 브라우저 소스 안에 있는 버튼(위플랩·씨미·치지직·투네이션 리모컨 등)을 스트림덱 키로 누르는 플러그인입니다. 상호작용 창을 열지 않아도 되고, 독이 다른 탭 뒤에 숨어 있어도 눌립니다.

만든 사람: 닥터고블린 김탄2

준비물

아래 네 가지가 갖춰져 있어야 합니다.

항목필요한 것
컴퓨터Windows 10 이상
스트림덱 프로그램Stream Deck 소프트웨어 7.3 이상
OBSOBS Studio (Windows 64비트)
설치 파일OBS-Browser-Click.streamDeckPlugin

누를 리모컨(위플랩, 씨미, 치지직, 투네이션)은 OBS에 사용자 지정 브라우저 독이나 브라우저 소스로 열려 있어야 합니다.

1단계: 플러그인 설치

  1. OBS-Browser-Click.streamDeckPlugin 파일을 더블클릭합니다.

  2. 스트림덱 프로그램이 열리면서 설치할지 물어봅니다. 설치를 누릅니다. 이미 설치되어 있어 덮어쓸지 물으면 이때도 설치를 고르면 됩니다.

  3. 스트림덱 프로그램 오른쪽 액션 목록에 OBS Browser Click 카테고리가 생겼는지 확인합니다.

2단계: OBS를 디버깅 옵션으로 켜기

플러그인은 OBS의 원격 디버깅 포트로 OBS 안의 페이지에 들어가 버튼을 누릅니다. 그래서 OBS를 --remote-debugging-port=9222 옵션을 붙여 켜야 합니다. 버튼 하나로 이 옵션이 붙은 바로가기를 만들 수 있습니다.

  1. 액션 목록의 OBS Browser Click에서 아무 액션이나 하나 키에 끌어다 놓고 클릭합니다.

  2. 아래 설정 화면 맨 밑의 [OBS 바로가기 설정]을 누릅니다.

  3. "바탕화면·시작 메뉴에 'OBS Studio (Browser Click)'를 만들었어요"가 뜨면 끝입니다. 작업 표시줄에 OBS를 고정해 두었다면 그 아이콘에도 옵션이 붙습니다.

  4. OBS를 완전히 끄고, 새로 생긴 OBS Studio (Browser Click) 바로가기(또는 작업 표시줄의 OBS)로 다시 켭니다.

주의: 원래 있던 "OBS Studio" 아이콘(공용 바탕화면, 시작 메뉴)으로 켜면 옵션이 빠집니다. 그 아이콘은 OBS 업데이트 때 다시 만들어지기 때문에 플러그인이 고치지 않습니다. 새 바로가기는 내 사용자 폴더에 있어서 OBS를 업데이트해도 지워지지 않습니다.

손으로 붙이는 법: OBS 바로가기 → 오른쪽 클릭 → 속성 → 대상 칸 맨 끝에 한 칸 띄우고 --remote-debugging-port=9222를 붙입니다. 시작 위치는 C:\Program Files\obs-studio\bin\64bit여야 합니다.

잘 켜졌는지 확인하는 법: 키에 OFFLINE이나 디버그 꺼짐이 뜨지 않으면 됩니다. 브라우저 주소창에 http://127.0.0.1:9222/json/list를 열어 페이지 목록이 나와도 됩니다.

디버깅 옵션을 켤 때 알아 둘 점

  • 이 PC 안의 다른 프로그램은 OBS 안의 페이지(로그인된 치지직·씨미 스튜디오, 위플랩 리모컨 등)를 보고 조작할 수 있습니다. 인터넷이나 일반 브라우저의 웹페이지에서는 들어올 수 없습니다(포트가 이 PC 안 127.0.0.1에만 열리고, 웹페이지의 접속은 OBS가 거절합니다). 모르는 프로그램을 설치하지 않는 것이 가장 중요합니다.

  • 포트 충돌: 크롬 개발 모드처럼 다른 프로그램이 같은 포트를 쓰면 OBS가 포트를 열지 못할 수 있습니다. 플러그인은 포트 너머가 OBS가 아니면 아무것도 누르지 않고 키에 OFFLINE을 띄웁니다. 이때는 아래 "설정"에서 포트를 바꾸고 [OBS 바로가기 설정]을 다시 누르세요.

  • 옵션 없이 켜짐: 원래 아이콘으로 켜거나 다른 프로그램이 OBS를 켜면 옵션이 빠집니다. 이때 키에 디버그 꺼짐이 뜹니다.

  • OBS 업데이트: 설치 프로그램이 공용 바로가기를 다시 만듭니다. 새 바로가기와 작업 표시줄 아이콘은 그대로 남지만, 혹시 옵션이 빠졌다면 [OBS 바로가기 설정]을 한 번 더 누르세요.

  • 성능: 영향은 거의 없습니다. 포트는 기다리기만 하고, 플러그인은 1초에 한 번 상태를 확인합니다.

3단계: 첫 키 만들어 보기

위플랩 후원 알림을 키 하나로 넘기는 예시입니다.

  1. 위플랩 대시보드에서 리모컨 주소를 복사해 OBS 메뉴 독 → 사용자 지정 브라우저 독에 추가합니다(이미 있다면 건너뜁니다).

  2. 액션 목록의 OBS Browser Click → 위플랩 리모컨을 키에 끌어다 놓습니다.

  3. 아래 설정 화면의 동작에서 알림 취소(넘기기)를 고릅니다.

  4. 키에 "알림 취소(넘기기)"가 뜹니다. 후원 알림이 나올 때 누르면 넘어갑니다.

처음 써 볼 때는 위플랩의 테스트 알림으로 먼저 확인해 보세요.

범용 클릭

목록에 없는 버튼을 누르거나, OBS 안 아무 페이지의 버튼을 누를 때 씁니다.

  1. 페이지: 지금 OBS에 열린 페이지 중 하나를 고릅니다. OBS를 방금 켰거나 독을 새로 추가했다면 [목록 새로고침]을 누릅니다.

  2. 방식에서 버튼으로 찾기 또는 위치 찍기를 고릅니다.

  3. 버튼으로 찾기: 버튼 목록에 그 페이지의 버튼이 글자로 나옵니다. 같은 글자가 여럿이면 시작 (2)처럼 번호가 붙습니다. 글자가 없는 아이콘 버튼은 CSS 선택자 칸에 적습니다(적으면 위 버튼 선택보다 우선).

  4. 위치 찍기: [화면 불러오기]를 누르면 페이지 캡처가 뜹니다. 누를 곳을 찍으면 빨간 점과 X, Y 값이 채워집니다.

위치 찍기 주의: 독이나 브라우저 소스의 크기를 바꾸면 같은 좌표가 다른 곳을 누를 수 있습니다. 크기를 바꾼 뒤에는 꼭 [화면 불러오기]로 위치를 다시 찍어 주세요. 클릭은 그 페이지 안으로만 전달되고 실제 마우스 커서는 움직이지 않습니다.

키 표시 바꾸기

키에는 평소 고른 동작 이름이 나옵니다. 스트림덱 프로그램의 제목 칸에 직접 글자를 넣으면 플러그인은 그 제목을 바꾸지 않습니다. 글자가 잘리면 제목 칸 옆의 T 버튼에서 글자 크기를 줄이세요.
