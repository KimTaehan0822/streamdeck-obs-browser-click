# OBS 브라우저 클릭 스트림덱 플러그인 설계

날짜: 2026-11-10 · 대상 저장소: `streamdeck-obs-browser-click` (새 저장소)

## 왜 만드나

방송 중 후원 알림을 넘기거나 멈추려면 OBS의 사용자 지정 독(리모컨)이나 브라우저 소스의 "상호작용" 창을 열고 마우스로 눌러야 합니다.
이 클릭을 **스트림덱 키 한 번**으로 바꿉니다.

- 사용 예 1: 위플랩 후원 알림을 넘기려고 상호작용 창을 여는 대신 키를 누릅니다.
- 사용 예 2: 독에 띄운 위플랩·치지직(·씨미·투네이션) 리모컨의 버튼을 키에 할당합니다.

## 시험으로 확인한 것 (2026-11-09 ~ 11-10)

- OBS 31을 `--remote-debugging-port=9222`로 켜면 `http://127.0.0.1:9222/json/list`에 **브라우저 소스와 사용자 지정 독이 모두** 페이지로 나옵니다.
  상호작용 창을 열지 않아도, 독이 화면에 안 보여도 접근됩니다.
- 이 통로(크롬 개발자 도구 프로토콜, 이하 CDP)로 페이지 안에서 `element.click()`을 실행하면 버튼이 실제로 눌립니다.
  - 투네이션 `알림 일시정지`: 누르면 글자가 `알림 일시정지중`, class에 `paused`가 붙음 → 다시 누르면 원래대로.
  - 위플랩 `일시 중지`: 누르면 글자 `다시 시작`, class `pause`→`play` → 다시 누르면 원래대로. **즉 토글입니다.**
- 스킵·취소 버튼은 대기 중 후원 알림이 사라질 수 있어 시험으로 누르지 않았습니다(구현 단계에서 테스트 알림으로 확인).
- 리모컨 주소(이 PC 기준)
  - 위플랩: `weflab.com/alertlist?mode=remote`
  - 씨미: `studio.ci.me/<번호>/rc`
  - 치지직: `studio.chzzk.naver.com/<채널ID>/remotecontrol`
  - 투네이션: `toon.at/widget/controller/<키>`
- 위플랩 버튼은 고정 id(`page_alert_cancel` 등)가 있습니다. 씨미·치지직은 class가 빌드마다 바뀌는 형태(`_button_1va5z_119`)라 **버튼 글자**로 찾아야 안전합니다.

## 목표

1. **리모컨 버튼 액션**(미리 만든 동작): 속성 창에서 목록 하나로 고릅니다. 서비스별로 묶어 보여줍니다. 아래 표의 동작을 **전부** 넣고, 쓰면서 필요 없거나 문제 있는 것은 뺍니다.
2. **범용 클릭 액션**: 목록에 없는 페이지·버튼을 직접 지정합니다.
   - 속성 창에서 지금 OBS에 열린 페이지 목록을 드롭다운으로 고릅니다.
   - 고른 페이지의 버튼 목록을 플러그인이 읽어서 두 번째 드롭다운으로 보여줍니다(버튼 글자 기준).
   - 목록에 없으면 "버튼 글자" 또는 "CSS 선택자"를 직접 입력할 수 있습니다.
3. **상태 표시**: 토글 버튼(일시정지, 켜기/끄기)은 키가 페이지 상태를 따라 두 가지 모습(켜짐/꺼짐)으로 바뀝니다. 기존 플러그인처럼 Stream Deck 상태 0/1을 써서 사용자가 상태별 아이콘·제목을 바꿀 수 있습니다.
4. **실패 알림**: OBS가 디버깅 모드가 아니거나(접속 실패) 페이지·버튼을 못 찾으면 키에 경고 표시(`showAlert`)와 짧은 문구(`OFFLINE`, `없음`)를 띄웁니다.

### 실페이지 확인 결과 (2026-11-10, 최종 목록은 `src/presets.ts` 29개)

- 씨미 `일시정지`, 치지직 `알림 정지`: 두 번 눌러도 글자·class가 그대로 → **토글 아님**(한 번 누르는 버튼). 알림이 재생 중일 때의 효과는 사용자가 테스트 알림으로 확인.
- 씨미 줄 구조: 줄마다 **켜기/끄기 토글 1개**(채팅·응원·영상·미션 후원, 워프 "팔로잉한 스트리머에게만 받기")와 알림/TTS/영상 **스피커 버튼**. 스피커는 켜짐 상태를 알 수 있는 class가 없고 개수도 줄과 맞지 않아(13개) 뺐습니다. 구독 알림·구독 선물 알림은 토글이 아니라 위젯 링크라 뺐습니다.
- 씨미 줄 제목은 피드·위젯 링크에도 나와서, "후보가 가장 적게 잡히는 줄"을 고르게 했습니다.
- 뺀 것(하나의 버튼이 아니라 목록마다 반복됨): 위플랩 `알림 사용 켜기/끄기`·`위젯 전체 새로고침`(위젯마다 13개), 투네이션 `재생`(지난 알림마다 21개). 범용 클릭으로는 지정할 수 있습니다.
- 뺀 것(입력칸을 채워야 의미가 있음): 위플랩 `적용` 버튼 3개, 타이머 위 공지 영역의 `시간/업타임/삭제`.
- 위플랩 타이머 `시간/업타임/삭제`는 공지 영역에 같은 글자가 먼저 있어 두 번째 것을 씁니다.

## 하지 않는 것

- 화면 좌표 클릭(마우스를 실제로 움직이는 방식). 창이 가려지거나 옮겨지면 깨지고, 방송 중 마우스를 뺏습니다.
- OBS를 대신 켜거나 바로가기를 자동으로 고치는 기능. 대신 설명서에 바로가기 고치는 법을 씁니다. _(제 판단)_
- 크롬 등 OBS 밖의 브라우저. (같은 방식이라 나중에 포트만 바꾸면 붙일 수 있습니다.)
- 일본어·영어 화면. 우선 한국어만. _(제 판단, 기존 플러그인처럼 3개 언어가 필요하면 다음 단계)_
- Elgato 마켓 배포, macOS.

## 실패로 치는 것

- 키를 눌렀는데 엉뚱한 버튼이 눌림(예: "현재 취소" 대신 "모두 취소"). → 글자 일치를 정확히(앞뒤 공백만 무시) 하고, 못 찾으면 **아무것도 누르지 않습니다.**
- 플러그인 때문에 OBS나 페이지가 느려짐. → 상태 확인은 화면에 보이는 토글 키만, 1초에 한 번.

## 방법 비교 (고른 것: A)

- **A. CDP(원격 디버깅 포트)로 페이지 안 버튼을 직접 누름** — 고른 방법. 창을 열 필요 없고, 창 위치와 무관하며, 버튼 상태도 읽을 수 있습니다. 대가: OBS를 옵션을 붙여 켜야 하고, 포트가 열려 있는 동안 이 PC의 다른 프로그램도 OBS 페이지에 접근할 수 있습니다(포트는 127.0.0.1에만 열림).
- B. 화면 좌표 마우스 클릭 — 위 "하지 않는 것" 이유로 제외.
- C. obs-websocket(+ obs-browser 이벤트) — 웹소켓에는 클릭 명령이 없고, obs-browser 이벤트는 페이지가 직접 받아 주도록 만들어져 있어야 해서 위플랩 등 남의 페이지에는 안 됩니다. 제외.

## 정한 구조

- 기존 `streamdeck-obs-audio`와 같은 틀: `@elgato/streamdeck` 3.0.4, TypeScript, rollup, `node --test`, `sdpi-components` 속성 창, Windows, Node 20.
- 플러그인 UUID `com.haeunga0822.obs-browser-click`, 이름 **OBS Browser Click** _(제 판단, 바꿔도 됨)_.
- 외부 라이브러리 추가 없음: Node 20에 내장된 `fetch`와 `WebSocket`으로 CDP를 씁니다. (Node 20의 `WebSocket`이 실험 기능이면 `ws` 패키지 하나만 추가)
- 액션 2개: `remote-button`(미리 만든 동작), `custom-click`(범용).
- 전역 설정: 디버깅 포트(기본 9222).
- 페이지 찾기: `/json/list`에서 `type === 'page'`이고 URL이 패턴에 맞는 것. 같은 패턴이 여러 개면 **첫 번째만** 누릅니다. _(제 판단)_
- 범용 클릭이 저장하는 페이지 주소는 쿼리(`?` 뒤)까지 포함한 전체 주소의 "포함" 비교입니다. 리모컨 주소에 들어 있는 키 값은 스트림덱 설정에만 저장되고 로그에는 남기지 않습니다.

## 만드는 사람에게 맡기는 것

- CDP 연결을 키 누를 때마다 새로 열지, 페이지별로 유지할지.
- 키 그림(기존 플러그인 렌더 코드 재사용 여부), 아이콘.
- 씨미 토글을 줄 제목으로 찾는 정확한 방법.
- OBS 바로가기에 옵션 붙이는 설명서 문구.
